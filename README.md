# 우주정복모임 아지트

우주정복모임 멤버들만을 위한 비밀 아지트입니다.

비밀번호를 입력하면 블랙홀 애니메이션과 함께 4개의 방으로 나뉜 우주 공간에 진입합니다.
각 멤버와 반려동물 캐릭터가 방 안에서 자유롭게 돌아다니며, 가구와 상호작용할 수 있습니다.

## Features

- 비밀번호 인증 + 블랙홀 진입 애니메이션
- 4개의 방에 배치된 멤버 & 반려동물 캐릭터
- 캐릭터 선택 및 키보드/터치 조작
- 가구 상호작용 (침대, 책상, 책장)
- 방별 고유 책 & 이펙트
- 우주 정복 BGM + 가사 보기
- 우주 댄스 파티 모드

## Tech

- Vanilla JavaScript + HTML5 Canvas
- 단일 파일 (`index.html`)
- 외부 라이브러리 없음
